SEA 254 Tours

SEA 254 Tours is a tourism website focused on showcasing Kenya and the experiences it has to offer. The website gives visitors an introduction to Kenya’s wildlife, culture, beaches and travel activities.

About the Project

SEA 254 Tours was my first web development project and the starting point of my journey into building websites.

As a Kenyan living abroad, I often get questions from people who are curious about Kenya, what life is like there and what they can experience when visiting.

This inspired me to build a website where people can discover more about Kenya and explore some of the places and experiences that make it a great destination for tourists.

The project gave me an opportunity to combine my interest in web development with something connected to my background. It was also a good learning experience that helped me put my HTML, CSS and JavaScript skills into practice.

Visitors can explore different activities, read about Kenya and find information about planning a trip.
